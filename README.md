# HR Analytics Dashboard – Power BI

## Overview
An interactive two-page HR analytics dashboard built with Microsoft Power BI using the IBM HR Analytics Employee Attrition dataset.

## Dashboard Pages

### 1. HR Overview
- Total employees, active employees, attrition count, and attrition rate
- Employee distribution by department and gender
- Age distribution
- Attrition count by department

### 2. Employee Analysis
- Average monthly income, average age, and average work experience
- Employee count by job role and education field
- Average salary and work experience by department
- Department, gender, and job-role slicers for interactive analysis

## Key Insights
- Total employees: 1,470
- Active employees: 1,233
- Employees who left: 237
- Overall attrition rate: 16.12%
- Sales has the highest departmental attrition rate at 20.63%.

## Tools and Skills
- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for calculated measures
- Data visualization and HR analytics
